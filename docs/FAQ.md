# Corrupted Portal: The Void World — Questions fréquentes

## Quelle version installer ?

CurseForge 0.1.1 ; build locale 0.1.3, MC 1.21.x et 26.x. Choisis celle qui correspond à ta version Minecraft ; lis la page CurseForge.

## Le guide a-t-il vérifié toutes les mécaniques ?

Non. Analyse des JAR universels 0.1.3 réalisée : douze modules MC 1.21 et cinq MC 26. Attention : CurseForge affiche 0.1.1. Complété par le document local de livraison 0.1.3.

## Comment obtenir de l'aide ?

Lorsque le dépôt sera créé sur GitHub, signale la version du fichier, celle du jeu, ton chargeur et les étapes qui reproduisent le problème.

# Installer Corrupted Portal: The Void World

**Version(s) repérée(s) :** CurseForge 0.1.1 ; build locale 0.1.3, MC 1.21.x et 26.x.

1. Installe la version Fabric adaptée et ses éventuelles dépendances.
2. Télécharge seulement le JAR correspondant à ta version de Minecraft.
3. Place le JAR dans mods/ (client et serveur selon la fiche).
4. Évite les doublons de versions et sauvegarde ton monde.
5. Teste sur une sauvegarde de test et lis latest.log en cas de problème.

## Avant d'installer

Analyse des JAR universels 0.1.3 réalisée : douze modules MC 1.21 et cinq MC 26. Attention : CurseForge affiche 0.1.1. Complété par le document local de livraison 0.1.3.

Vérifie la page CurseForge : https://www.curseforge.com/minecraft/mc-mods/corrupted-portal-the-void-world.

# Corrupted Portal: The Void World — English overview

A Fabric Void dimension mod with unstable rifts, corrupted monsters and equipment. Local 0.1.3 bundles contain 12 Minecraft 1.21 and 5 Minecraft 26 modules.

**Official CurseForge page:** https://www.curseforge.com/minecraft/mc-mods/corrupted-portal-the-void-world

**Files/versions:** CurseForge 0.1.1 ; build locale 0.1.3, MC 1.21.x et 26.x.

Install Fabric mods in a matching mods/ setup, datapacks in the world's datapacks/ folder, Bukkit plugins in a compatible server plugins/ folder, and modpacks using a compatible launcher. Back up your worlds and verify compatibility before updating.

The French guide and verification notes are available from the [home page](../README.md).
